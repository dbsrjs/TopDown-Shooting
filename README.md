# TopDown Shooting

# Control
- W = 앞으로 이동
- A = 왼쪽으로 이동
- S = 뒤로 이동
- D = 오른쪽으로 이동
- R = 장전
- Left Button = 발사

# Information
1. 라운드마다 플레이어의 무기가 바뀝니다.
2. 라운드마다 플레이어, 적의 스텟이 바뀝니다.

# How to play video games
- 적을 쳐치서 스테이지를 높여가세요.
